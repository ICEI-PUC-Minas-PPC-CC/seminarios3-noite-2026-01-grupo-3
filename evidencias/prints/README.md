## Prints de Tela

Esta pasta contém evidências visuais do MVP desenvolvido para a Etapa 3 do projeto de Seminários III.

Os prints demonstram as principais telas da aplicação educacional de prática de operações matemáticas básicas, desenvolvida em Python com Streamlit.
